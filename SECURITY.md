# Security policy

## Supported versions

Security fixes are released for the latest minor version of `masilia/ibexa-sites`. Please upgrade to it before reporting a problem.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Report it privately through GitHub: open the [Security tab](https://github.com/MasiliaLabs/ibexa-sites/security/advisories/new) of this repository and choose *Report a vulnerability*. Include:

- the version of the package and of Ibexa you use;
- what an attacker can do and the steps to reproduce it;
- any suggestion for a fix.

You will get an answer as soon as a maintainer can read it, and we will agree with you on a date for the disclosure once a fix is available.
